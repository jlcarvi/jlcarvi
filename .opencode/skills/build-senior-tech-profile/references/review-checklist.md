# Senior Technical Profile Review

A visitor should understand within 10–15 seconds:

- Seniority
- Cloud/Data Platform identity
- Architecture capability
- Hands-on implementation capability
- AWS + IaC strength
- Distributed-systems depth
- Industrial IoT specialization

Within 30 seconds they should also understand:

- why this background transfers well to Space/GNSS;
- that Space/GNSS is an emerging specialization rather than invented experience;
- where engineering evidence can be found.

## Fail the review if

- PhD dominates the opening
- profile reads primarily as IoT Engineer
- profile reads primarily as DevOps Engineer
- Space experience is exaggerated
- technology inventory replaces professional story
- unsupported projects are presented
- excessive badges or visual gimmicks dominate
- generic AI-generated language appears
- architecture is visible but implementation is not
- implementation is visible but architecture is not
